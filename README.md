# Misión: Desafío Científico v2

## Qué trae esta versión
- Mantiene el formato general de la v1.
- Fotos reales de Marie Curie, Antoine Lavoisier y Dolph Lundgren.
- 5 niveles por personaje.
- Explicación breve ANTES de cada pregunta.
- Imagen relacionada con el tema.
- Bloque "¿Qué acabás de aprender?" después de responder correctamente.
- Pistas ante respuestas incorrectas.
- El estudiante NO puede avanzar hasta acertar.
- Puntaje: 100 / 75 / 50 / 25 según intento.
- Cronómetro.
- Diseño adaptable a celular, tablet y computadora.
- Voz de respaldo mediante la voz disponible en el navegador.
- Preparado para incorporar audios MP3/WAV propios.

## Voces propias
Sí, se pueden incorporar audios que tengas autorización para usar.

La idea para la próxima versión es:
assets/audio/
  curie_1.mp3
  curie_2.mp3
  ...
  lavoisier_1.mp3
  ...
  dolph_1.mp3
  ...

El juego puede reproducir esos archivos en lugar de la voz automática. También se puede usar un audio de presentación por personaje.

No hace falta que los audios sean perfectos: puedo adaptar el juego a la duración y cantidad de grabaciones que tengas.

## Importante sobre las fotos
Las fotografías de Marie Curie y el retrato de Lavoisier usados en esta versión provienen de Wikimedia Commons y sus páginas indican dominio público/CC0 según el archivo.
La foto de Dolph Lundgren 2018 de Wikimedia Commons está bajo CC BY-SA 4.0 y requiere atribución al fotógrafo Glenn Francis.

Fuentes:
- Marie Curie: https://commons.wikimedia.org/wiki/File:Portrait_of_Marie_Curie.jpg
- Lavoisier: https://commons.wikimedia.org/wiki/File:Lavoisier.jpg
- Dolph Lundgren: https://commons.wikimedia.org/wiki/File:Dolph_Lundgren_2018.jpg

## Cómo ejecutar
1. Descomprimí el ZIP.
2. Abrí index.html con Chrome, Edge o Firefox.
3. Para compartir por QR, subí la carpeta a un servicio de alojamiento web estático (por ejemplo GitHub Pages).
4. El navegador necesita internet para cargar las fotografías alojadas en Wikimedia Commons.

## Nota didáctica
Dolph Lundgren aparece como personaje motivacional para relacionar ciencia, movimiento y entrenamiento. El juego no lo presenta como autor de investigaciones científicas.
